# 🚀 Frontend Projects

A collection of beginner-friendly frontend projects built using **HTML, CSS, and JavaScript**.

These projects helped me practice DOM manipulation, JavaScript logic, events, user input, functions, timers, and basic frontend development.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Events

---

## 📂 Projects

### 1. 💬 Random Quote Generator
Generates and displays a random motivational or interesting quote whenever the user clicks a button.

**Concepts:** JavaScript Arrays, Functions, DOM Manipulation, Events

---

### 2. 📝 To-Do List
Allows users to add tasks, mark tasks as completed, and delete tasks from the list.

**Concepts:** DOM Manipulation, Events, Arrays, User Input

---

### 3. 🎨 Color Changer
Changes the background color of the webpage when the user interacts with the button.

**Concepts:** DOM Manipulation, Events, CSS Properties

---

### 4. 🕐 Digital Clock
Displays the current time and automatically updates every second.

**Concepts:** Date Object, `setInterval()`, DOM Manipulation

---

### 5. ⏳ Countdown Timer
Counts down from a specified time until the timer reaches zero.

**Concepts:** Date Object, `setInterval()`, Time Calculation

---

### 6. 🔮 Astrology
Takes user information and displays basic zodiac/astrology-related information.

**Concepts:** Forms, Conditions, DOM Manipulation, JavaScript Logic

---

### 7. 🖱️ Clicker
Counts the number of times a user clicks a button and provides reset functionality.

**Concepts:** Variables, Functions, Events, DOM Manipulation

---

### 8. ❤️ Love Calculator
Takes two names as input and generates a fun compatibility percentage.

**Concepts:** User Input, Functions, DOM Manipulation, JavaScript Logic

---

### 9. 💰 Income Tax Calculator
Takes the user's income and calculates estimated tax based on predefined rules.

**Concepts:** Conditions, Functions, User Input, Mathematical Operations

---

### 10. 🧠 Quiz
Displays multiple-choice questions and calculates the user's score based on their answers.

**Concepts:** Arrays, Objects, Conditions, Events, DOM Manipulation
